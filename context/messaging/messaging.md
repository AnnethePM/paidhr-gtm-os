# PaidHR messaging

Built only from `context/docs/research/`. Approved numbers and names live in `context/messaging/facts.md`; copy uses those, not this file.

## Core message

Run payroll on time and file every statutory remittance automatically, with proof, in one platform your team and your employees can both use.

Sources: voice.md ("Payroll that never misses payday", "Compliance filed on time, automatically."); customer-videos.md: Heroshe (receipts).
